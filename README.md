# gitty

A TypeScript CLI for interacting with GitHub repositories, issues, and workflows from your terminal.

## Installation

### Prerequisites

- Node.js 20.x

```shell
$ npm i -g @waffledood/gitty
```

## First-time Setup

When using `gitty` for the first time, you will need to set it up. Run the command:

```shell
$ gitty auth setup
```
